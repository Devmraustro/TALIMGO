## قواعد لا تُكسر أبداً

1. **ذكاء اصطناعي محلي مستضاف ذاتياً ومفتوح الأوزان فقط** — ممنوع أي مزوّد خارجي
   (OpenAI/Anthropic/Google…)، والفشل عند غياب النموذج يجب أن يكون صريحاً (fail-closed).
   يوجد سكربت فحص `backend/scripts/check_no_external_ai.py` يجب أن يبقى أخضر.
2. المحرك التعلّمي (`backend/app/learning/`) يبقى **دوال نقية حتمية** بلا I/O.
3. كل كائن يُتحقق من ملكيته في الخادم؛ لا تثق بأي معرّف من العميل.
4. **لا تخترع قرارات المالك**: بنود `DEC-*` في `TALIMGO_MASTER_REFERENCE.md` §19 والعلامة
   التجارية (§21) والأسعار والحد العمري والنصوص القانونية واختيار النموذج — تُسأل للمالك
   ولا تُصاغ نيابة عنه. جهّز له قوائم أسئلة وخيارات، ولا تُدخل إجابات مخترعة.
5. انضباط الحالة: لا تدّعي TESTED/CI-verified دون مخرجات مشاهَدة فعلاً. كوميتات صغيرة
   مسمّاة (وموقّعة لديك) على فرع ميزة، وتحديث `docs/IMPLEMENTATION_PLAN.md` بقسم جديد لكل دفعة.

## مهامك مرتبة (نفّذ وتحقق من كل واحدة قبل التالية)

### 1) إغلاق حلقة هذا الفرع
- ادمج **PR #5** في `main` (CI أخضر أصلاً؛ إن ظهر فشل جديد أصلحه)، وادفع بكوميت موقّع حتى
  تنجح معاينة `talimgo-preview` على Vercel، وتحقق من روابط المعاينة حياً.
- لقطة/جولة متصفح حقيقية للرحلة الكاملة: تسجيل → هدف لكل مسار → تشخيص → خطة → تدريب
  بأنواع الأسئلة الستة → مشروع مقبول → مراجعة وبطاقات. وثّقها في قسم جديد بالخطة.

### 2) تشغيل الخادم فعلياً (أولوية قصوى — بدونها لا يوجد منتج)
اتبع `docs/DEPLOYMENT.md` و`docs/UBUNTU_PREDEPLOYMENT_RUNBOOK.md` حرفياً على جهاز/خادم المالك:
- PostgreSQL حقيقي + `DATABASE_URL` وأسرار (`TALIMGO_SECRET_KEY`…) من `.env.example`.
- `alembic upgrade head` على قاعدة فارغة ثم `alembic check` = بلا انحراف.
- تحميل المناهج (`load_all`) والتحقق أن العدّادات: مساران، 20 هدفاً، 68 عنصراً، مشروعان.
- systemd + Nginx من `deploy/` وفحص `browser-smoke` عبر الحافة.
- على Vercel: `talimgo-api` يبني READY الآن؛ التشغيل الكامل ما زال يحتاج قاعدة خارجية
  وأسرار بيئة (Serverless لا يستضيف نموذجاً محلياً — هذا مقصود ومُوثّق).
- حدّث `docs/VERCEL_DEPLOYMENT_STATUS.md` بنتائج مشاهَدة بتاريخها.

### 3) النموذج المحلي الحقيقي (إثبات لا ادعاء)
- على عتاد المالك: شغّل وقتَ تشغيل محلياً (Ollama أو llama.cpp) بنموذج مفتوح الأوزان يختاره
  **المالك** (قرار DEC — اسأله؛ اقترح Qwen2.5-Instruct بحجم يناسب العتاد مع مقارنة أحجام).
- صِل `TALIMGO_AI_*`، فعّل اختبارات التكامل المُتخطاة حالياً (4 skipped) حتى تنجح فعلياً،
  واختبر المعلّم الذكي حياً بعربية وإنجليزية، ووثّق زمن الاستجابة والعتاد في قسم جديد بالخطة.

### 4) البريد: تحقق + استعادة كلمة المرور
- يحتاج قرار مالك عن وسيلة الإرسال (SMTP على خادمه مفضلاً للاتساق مع "محلي فقط"، أو مزوّد
  بريد معاملات — ملاحظة: مزوّد بريد ليس مزوّد AI لكن اسأل المالك ولا تقرر وحدك).
- التنفيذ: رموز موقّعة منتهية الصلاحية، استخدام واحد، حدود محاولات، ردود غير مميِّزة لوجود
  الحساب، إبطال الجلسات عند الاستعادة، اختبارات على غرار `test_account_lifecycle.py`،
  ثم حدّث وعود صفحة المساعدة (نصّها الحالي صادق بأن لا استعادة بعد).

### 5) الدفع (فقط بعد قرارات مالك مكتوبة)
- اسأل المالك: هل يوجد دفع في MVP أصلاً؟ أي مزوّد/بلد/عملة/أسعار؟ بدون إجابات لا تبنِ شيئاً
  سوى تصميم مقترح في ADR.

### 6) أحداث تحليلات دنيا تحترم الخصوصية
- خادمية فقط، بلا أي خدمة خارجية: جدول أحداث (تسجيل، هدف، تشخيص مكتمل، جلسة مكتملة، مشروع
  مقبول) + صفحة مشرف للعدّادات. لا محتوى دراسة في الأحداث.

### 7) مراجعات بشرية لا يستطيع أي وكيل ادعاءها
- مراجعة موضوعية لمحتوى المسارين (خاصة `frontend-foundations` الموسوم PROPOSED) من مختصَّين.
- تدقيق WCAG بشري (قارئ شاشة فعلي، تنقّل بلوحة المفاتيح، تباين) فوق الفحوص الآلية الموجودة.
- اختبار اختراق (pentest) على بيئة نشر حقيقية قبل أي إطلاق عام.

### 8) بوابة الجاهزية
- امشِ على `TALIMGO_MASTER_REFERENCE.md` §24 بنداً بنداً وحدّث حالته بأدلة، و§15 خارطة MVP،
  وسجلّ المتطلبات §17. ما يبقى معلقاً بقرار مالك يُترك مفتوحاً صراحة.

## أوامر التحقق المرجعية

```bash
# Backend
cd backend && . .venv/bin/activate  # أو أنشئها: python -m venv .venv && pip install -e ".[dev]"
python -m pytest -p no:warnings        # الهدف: ≥446 passed
ruff check app tests scripts && ruff format --check app tests scripts && bandit -q -r app
python scripts/check_no_external_ai.py
alembic upgrade head && alembic check   # على قاعدة الاختبار لديك

# Frontend
cd frontend && npm ci && npm run typecheck && npm test && npm run build
node scripts/check-bundle.mjs --dist dist && node scripts/check-licences.mjs && npm audit
```
